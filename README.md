# DocFlow 文流 · 智能文档整理（重构版）

本地优先的文档自动整理工具：文件进目录，自动识别、重命名、分类、归档；拿不准的交人工；
台账对账、邮箱收件、目录监控无人值守。**机器处理确定的事，人处理不确定的事。**

本工程是隔壁 `smart-document-organizer` 的重新设计版，功能对齐并增强，安全与体验重点修复；
原版代码零改动，两库可并存（注意别同时占用 8000 端口）。

## 快速开始

```powershell
python -m pip install -r requirements.txt
python -m pytest tests -q        # 84 项测试（端到端识别/预览/自检/对账/归集/安全/失效记录/桌面壳）
python run.py                    # 打开 http://127.0.0.1:8000（自动开浏览器）
python run.py --lan              # 局域网共享：自动生成/沿用访问密码并打印
```

前端已构建在 `frontend/dist`，后端单进程托管；开发模式 `cd frontend && npm run dev`（5173，代理 /api）。

## 桌面版（DocFlow.exe，免 Python）

双击 `dist\DocFlow\DocFlow.exe` 即可，单文件目录里自带 Python 运行时、OCR 模型、PyMuPDF 和前端资源，
装完即用、全程离线。

| 事项 | 说明 |
|---|---|
| 数据目录 | `%LOCALAPPDATA%\DocFlow`（数据库/归档/回收站/备份/日志），首次启动自动创建 |
| 界面 | 原生窗口（系统 WebView2）；缺依赖、创建失败或窗口 20 秒没加载完成，自动改用浏览器界面 |
| 重复启动 | 带实例锁，第二次双击会把已有窗口唤到前台，不会起两份服务 |
| 命令行 | `DocFlow.exe` 开窗口；`--serve` / `--no-window` 只跑服务；`--lan` 局域网；`--port 8123` 指定端口 |
| 环境变量 | `DOCFLOW_HOME` 换数据目录、`DOCFLOW_PORT`、`DOCFLOW_HOST`、`DOCFLOW_DEBUG=1` 开 DevTools、`DOCFLOW_SHELL=webview|browser` 强制界面形态 |
| 日志 | `%LOCALAPPDATA%\DocFlow\logs\desktop.log`（窗口/端口/回退都记在这里） |

重新打包（源码目录里执行，产物在 `dist\DocFlow\`）：

```powershell
cd frontend; npm ci; npm run build; cd ..
python -m pip install pyinstaller pywebview
python 发布桌面版.bat            # 等价于 python -m PyInstaller packaging/docflow.spec --noconfirm
```

远程桌面 / 无显卡虚拟机上若窗口画不出来，设 `DOCFLOW_WEBVIEW_FLAGS=--disable-gpu` 再启动。

把桌面版分发给他人、以及后续功能更新如何同步，见 `docs/发布与更新.md`。

### 窗口“无响应”了怎么办

原生窗口一旦在 20 秒内没有完成加载，启动器会记下这个事实（数据目录下的 `.window-state`）、
立刻改用浏览器界面，**下次双击直接进浏览器界面**，不会再让你对着一个卡死的窗口。

- 想再试原生窗口：删掉 `.window-state`，或用 `DOCFLOW_SHELL=webview DocFlow.exe` 启动一次。
- 只想稳定用浏览器界面：`DOCFLOW_SHELL=browser`（或 `DocFlow.exe --no-window`）。
- 常见根因是 WebView2 运行时/显卡驱动异常，更新「Microsoft Edge WebView2 运行时」后重试。

### 文件被外部删掉的记录（“删不掉也移不进回收站”）

现在这类记录可以正常处理：移入回收站会成功（回收站里标为「文件已丢失」，恢复按钮置灰，
彻底删除照常）。文档库对这类记录显示「文件缺失」标签，设置 → 系统自检的
「记录与磁盘一致性」会列出它们并提供一键清理。
AI 可不配置：纯规则 + OCR + 样例库即可自动归档（权重自动归一化）。

## 与旧版的关键差异（详见 DESIGN.md）

| 主题 | 旧版 | DocFlow |
|---|---|---|
| 静态托管 | SPA 兜底路由可被 `%2F` 穿越读任意文件 | safe_join 守卫，越界 400 |
| 备份恢复 | zip 成员不校验（zip-slip） | 成员路径守卫 + 数据库一致性导入 |
| 监听 | 启动器硬编码 0.0.0.0 | 默认 127.0.0.1；`--lan` 时强制配密码 |
| 会话 | HMAC(固定盐,密码)，永不过期 | 随机令牌 + 过期 + 登录限速 |
| 搜索 | 文件名/字段 LIKE | SQLite FTS5 全文（正文可搜、片段高亮）|
| 正文 | 截断 5000 字 | 全文入库不截断 |
| 整理 | 只扫目录第一层 | 递归扫描 + 文件稳定性门槛 + 忽略临时文件 |
| 崩溃 | running 任务可能卡死 | 启动自动恢复 interrupted → pending |
| 审核 | 聚类批确认 | 聚类批确认 + 键盘流 + 纠错自动生成候选规则 + 一键存样例 |
| 无人值守 | 手动备份、回收站只进不出 | 每日自动备份轮转、回收站到期自动清理 |
| 邮箱 | 仅收件 | 收件 + 发件人白名单 + 主题「整理[分类]:」路由 |
| 上传 | 整包进内存 | 流式写盘 + 200MB 上限 |
| 预览 | 只有元数据接口 | 文档库/审核/回收站/台账全都能就地预览（PDF 逐页+可选文本层、图片、表格、正文）|
| 交付 | 必须装 Python | 桌面版 `DocFlow.exe` 单目录免安装，自带 OCR 模型与前端资源 |
| 排障 | 靠翻日志 | 设置 → 系统自检：18 类体检 + 一键修复（含表结构漂移、文档归集一致性），顶栏常驻状态徽标 |

## 文档归集（业务包）

一份业务 = 一个包：同一合同号下的采购合同、销售合同，以及它们各自的发票、结算单、
提货单/入库单，归档时自动归进同一个业务包，包内按「合同锚点」分组并显示必备单据齐备度（3/4）。

- **必备单据可配**：规则中心 → 归集与必备单据，按合同类型配置需要哪些随附单据、至少几份、是否核对金额
  （销售合同→发票/结算单/提货单，采购合同→发票/结算单/入库单）。
- **缺什么补什么**：详情页把缺失角色显示成虚线占位瓦片，点「上传」就地补单 → 识别归档 → 自动入包 → 齐备度当场重算。
- **合同号是唯一口径**：`contract_key`（归一化合同号）上有唯一索引，一个合同号只有一个包；手工包可以「认领」
  合同号，占号的自动包会被并进来；历史竞态留下的分裂包在启动自检时自动合并。
- **合并建议**：方向相反、对方单位相同、金额相对差 ≤5%、签订日期相距 ≤30 天的销售包与采购包会提示成对
  （阈值见设置 → 无人值守 → 文档归集）；合并只搬条目并写操作日志，可先忽略、也能恢复显示。
- 无合同编号的文档不自动入包，只能在归集页手工建包后拖入；设置 → 系统自检新增「文档归集」一致性项。

## 对账口径

台账 Excel 三张表自动识别（合同台账/结算/回款，表头别名可自动探测）；
对归档文档按 **合同编号变体 + (对方单位,金额) 双通道** 匹配，产出七类差异：
缺必备单据 / 缺结算单据 / 未回款 / 金额不符 / 文档无台账 / 日期可疑 / 疑似缺章。

**每条差异都带依据**：点「依据」打开抽屉，显示对应业务包、已匹配的文档（就地预览）、还缺哪些单据，
缺的那一项自带上传入口——上传 → 识别归档 → 入包 → 复核，条件满足即自动关闭并留痕
（`由文档 #12《发票_…》自动补齐发票`），不满足则原地写明「仍缺 提货单」。

**没有台账也能查**：数据源选「档案库自对账」时以已归档合同为锚，期望值取合同金额/签订日期，
实际值取包内发票·结算单与银行回单汇总，检查项与台账模式完全一致；默认「自动」= 有台账用台账，没台账走档案库。
金额比对按单据类型分桶取偏差最大的一类，避免发票+结算叠算出假差异；标记已处理/复核后本期统计同步重算。

差异标记跨期结转，支持 CSV/Excel 导出与定时巡检。
